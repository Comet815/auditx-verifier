缺陷清单

F-001 严重 security sustained

会话令牌直接使用用户 ID，伪造后可冒充任意账号

const token = req.headers["x-session"]session.js:5
const user = users[token]session.js:8

位置：artifact/session.js:8

裁定理由：证据明确，可复现，维持原判。

整改建议：改用随机签发、可撤销、带过期的会话令牌；用户 ID 不参与鉴权。

F-002 严重 logic sustained

库存检查与扣减不在同一事务，并发结算可超卖

if (goods.stock <= 0) throw new Error("out of stock")checkout.js:9

位置：artifact/checkout.js:7-11

裁定理由：证据明确，可复现，维持原判。

整改建议：把校验与扣减放进同一事务，或用带条件的原子更新（stock > 0 时自减）。

F-003 一般 security sustained

兑换码使用 Math.random 生成，可预测

out += chars.charAt(Math.floor(Math.random() * chars.length))codes.js:7

位置：artifact/codes.js:7

裁定理由：证据明确，可复现，维持原判。

整改建议：改用 crypto.randomBytes / crypto.getRandomValues。

整改条件

  1. F-001 改为可撤销的随机令牌
  2. F-002 校验与扣减进同一事务
  3. F-003 换密码学安全随机源
