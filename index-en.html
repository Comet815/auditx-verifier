AUDITX · VERIFIER

Don't trust me. Recompute it yourself.

An independent verifier for review ledgers. Everything below runs locally in your browser: hash chain, Ed25519 signatures, final digest, artifact manifest. No network, no upload, no backend.
✓ Original ledger
12 signed events, untouched — should show “verified”
✕ Tampered ledger
Same ledger, one word changed at event 6 — should show “verification failed”
⚑ Handoff case
A script that passes the gates but should not ship — 3 findings, REJECT

What it actually computes

  1. Whether each event's hash matches what the ledger recorded (one character off and it fails)
  2. Whether the hash chain connects (delete or insert an event and it breaks)
  3. Whether each Ed25519 signature was produced by the corresponding key
  4. Whether the final digest matches the finding counts
  5. Whether the artifact manifest was swapped
Source and CLI verifier: Comet815/auditx-verifier. The browser kernel implements SHA-256, SHA-512 and Ed25519 from scratch — no third-party libraries.
All example cases are synthetic. No real client data is included.
