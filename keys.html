AuditX 签名公钥指纹

本页是本项目的指纹公布渠道。请以本页内容为准，不要只信压缩包里的 pubkey.pem。

每一份 AuditX 审查报告都用 Ed25519 私钥逐条签名。验证报告时，你需要确认「这把公钥确实属于出报告的人」—— 这一步的信任起点就是下面的指纹。指纹对不上，报告全绿也没有意义。

怎么用这些指纹

  1. 拿到一份 AuditX 报告，先看报告里标注的公钥指纹。
  2. 用本页或合同附件的指纹去比对。两个渠道都对得上，才继续下一步。
  3. 指纹一致 → 打开报告里的 verify.html，在浏览器本地重算哈希链与签名。
  4. 「V1–V11 全部通过」只说明这份账本自签发以来没有被改动过，不代表审查结论一定正确。边界见 README「边界」。
不要做的事：不要只用报告压缩包里自带的 pubkey.pem 验证。 那个文件可以连同报告一起被替换。指纹要通过独立渠道获取——本页，或者合同附件。

指纹是怎么算的

公钥的原始 32 字节（Ed25519 Raw 格式）做 SHA-256，取 Base32 编码的前 32 位，前缀 SHA256:：

SHA256: + Base32( SHA256( pubkey.raw_bytes ) )[:32]

你可以自己算，不必信任本页的计算：

python -c "
import base64, hashlib
from cryptography.hazmat.primitives import serialization
pub = serialization.load_pem_public_key(open('pubkey.pem','rb').read())
raw = pub.public_bytes(serialization.Encoding.Raw,
                       serialization.PublicFormat.Raw)
print('SHA256:' + base64.b32encode(hashlib.sha256(raw).digest()).decode()[:32])
"
